# Climate Data Analysis & Visualization

## Overview
This project looks at global surface temperature changes from 2000–2022 using climate data originally sourced from the UN Food and Agriculture Organization (FAO). I used Python to clean the data and look at how temperature changes differed across countries and regions over time.

## Analysis
I used Pandas to clean and organize the dataset, calculate temperature averages, and compare changes across countries and regions. I also grouped the data by region to look at broader warming trends and used Matplotlib to visualize how temperatures changed over time.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib

## Files
- climate_data_analysis.ipynb — Main analysis notebook
- data/ — Datasets used in the analysis

## Data Source
Surface temperature change data originally sourced from the Food and Agriculture Organization of the United Nations (FAO).
